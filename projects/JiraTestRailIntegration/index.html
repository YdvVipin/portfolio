✨ Key Features

🎯 AI-Powered Generation

Uses Grok-3 AI trained on real team examples to generate test cases matching exact writing style and terminology.

🛡️ Duplicate Protection

Automatically checks existing TestRail cases to prevent duplicates with case-insensitive title matching.

📁 Smart Section Management

Auto-creates TestRail sections from Jira Epic fields with fallback to "General" section.

🔍 Dry Run Mode

Preview what would be created without generating test cases - perfect for testing and validation.
