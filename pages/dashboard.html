Quality Dashboard

This site tests itself. Every push to main runs Playwright, axe and Lighthouse in GitHub Actions, and the results land here — real numbers, no mock data.

Loading latest results…

How this works

  1. Push — any commit to main triggers the Site Tests workflow.
  2. Test — Playwright checks every page on desktop and mobile: clean loads, links, layout, nav, theme, and axe WCAG 2 A/AA.
  3. Measure — Lighthouse scores the home, projects and flagship pages.
  4. Record — a script appends the run to data/qa-metrics.json and commits it back; this page reads that file.
